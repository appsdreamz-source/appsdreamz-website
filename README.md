# AppsDreamz website (static)

Oracle Fusion HCM specialist consultancy site. Plain HTML, one stylesheet, one script. No framework, no runtime.

## How it is built

Every page is generated by `tools/build.js` from a shared layout (header, menus, footer, structured data).
Edit page content in `tools/build.js`, then run:

```
node tools/build.js
```

This rewrites all pages, the redirect stubs for old URLs and `sitemap.xml`. Commit the generated files: GitHub Pages serves them as they are.

- `assets/site.css`: design tokens and components (brand kit below).
- `assets/site.js`: menus, mobile sticky button, booking form validation and submission.
- `images/`: logo, icon mark, OG image, partner logos (`images/logos/`), founder photos (`images/team/`).

Old URLs (`services.html`, `work.html`, `contact.html` and others) redirect to their new pages.

## Booking form

With no form service configured, the form validates, then opens the visitor's email app with the request addressed to aneel@appsdreamz.com.
To submit directly instead, set `FORM_ENDPOINT` at the top of `assets/site.js` to a Formspree, Web3Forms or HubSpot endpoint.

## Brand

Follows the AppsDreamz Brand Kit: official primary logo (`images/appsdreamz-logo.png`) and icon mark (`images/appsdreamz-mark.png`, used as favicon); Navy #071C35, Cyan #29ABE2 (shapes and text on dark only), Deep Cyan #0B6E9C (links and accent text on light), Slate #5B6B7C, Ice #E8F6FC, Mist #F4F8FB. Inter Tight (headings) and Inter (text) from Google Fonts. Logo shown at 140 px wide or more, unmodified.
