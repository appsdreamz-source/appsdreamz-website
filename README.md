# AppsDreamz website (static)

Built from the Claude Design export `AppsDreamz Oracle Fusion HCM.html`
(the home page, "AppsDreamz Website v3" in the design project).

- `index.html` — home page. Plain HTML/CSS, no runtime or framework.
- `fonts/` — Source Serif 4 (400/500/600/700) and IBM Plex Mono (400/500), self-hosted woff2.
- `images/` — hero and figure photos, AppsDreamz logo, partner logos under `images/logos/`.

Serve the folder with any static host. Nav and footer links currently jump to sections on the home page. Dedicated pages still to be built:
pages that were not part of this export and still need to be built:
`module-coverage.html`, `how-we-work.html`, `work.html`, `health-check.html`,
`design-review.html`, `talent-and-recruiting.html`, `contact.html`.
